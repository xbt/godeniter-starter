原生计划任务
内置秒级与 Linux Crontab 调度引擎
100% 纯 Go 自研调度内核，对标 Linux Crontab。支持 6 段秒级（*/15 * * * * *）与 5 段经典分级，支持 @hourly 宏语法、Panic 容错隔离与手动 Trigger 即时执行。
// 秒级或分级注册调度任务
app.Schedule("heartbeat", "巡检", "*/15 * * * * *", fn)
app.Schedule("cleanup", "清理", "@hourly", fn)

0-CGO 桌面客户端
跨平台桌面托盘与无黑框运行 (tray)
Windows 端纯 Go syscall 调用 Win32 API 自动隐藏控制台黑框；macOS 端原生接入 Cocoa 状态栏常驻。支持右键唤起菜单：打开后台、定位数据目录、关于系统与优雅退出。
// 命令行或双击独立 exe 启动桌面托盘
go run main.go tray
// 托盘右键菜单: 打开后台 / 应用目录 / 优雅退出

服务生命周期
跨平台守护进程服务化 (daemon)
单二进制接管生命周期。支持类 Nginx 指令集：start（Setsid 脱离终端后台静默守护，记录 PID 并重定向日志）、stop（平滑停机）、status（运行状态查询）、restart（平滑重启）。
./godeniter-starter start # 后台静默守护
./godeniter-starter status # 查看 PID 与状态
./godeniter-starter stop # 优雅平滑停机
📋 架构特性
跨平台兼容 Linux/macOS 系统会话与 Windows DETACHED 独立进程模型，断开终端服务持续稳定运行。

参数绑定与校验

  Title string `binding:"required,min=3,max=80"`
} → c.BindAndValidate(&req)
