⚡ Godeniter 2.0 框架特性全景体验中心

100% 纯 Go 标准库打造 · 0 第三方依赖 · 极简优雅 · 开箱即用

⏱️
中间件流水线
响应计时与安全防护头
框架采用洋葱圈中间件模型。本项目已挂载 ResponseTimer() 与 SecurityHeaders()，会自动为每个响应注入计时和安全防御标头。
Header: X-Response-Time
Header: Server-Timing
Header: X-Content-Type-Options: nosniff
🛡️
容灾与可用性
Panic 优雅恢复 (Recovery)
任何业务逻辑或未捕获的空指针异常，均由 middleware.Recovery() 拦截并输出彩色堆栈，服务端返回 500，进程永远不宕机！
panic("故意触发的异常") → 捕获恢复 → 保持服务可用

🖼️
文件上传机制
封面上传与静态资源服务
通过 SaveUploadedFileWithOptions 实现 5MB 限制、扩展名白名单校验与自动安全重命名，配合 app.Static 极速静态分发。
opts := upload.Options{
SaveDir: "./uploads/images",
MaxBytes: 5*1024*1024, AutoRename: true
}
📸 去后台发布页体验上传
✅
参数绑定与校验
零依赖参数校验器
基于纯 Go 反射实现的 Validator。无需引入任何第三方库，声明 binding:"required,min=3,max=80" 即可完成字段校验。
type FormArticleRequest struct {
Title string `binding:"required,min=3"`
} → c.BindAndValidate(&req)
发布/编辑文章时故意提交过短标题即可触发
